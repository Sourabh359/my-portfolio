# Sourabh Malik | Frontend Developer Portfolio

A modern, responsive, and user-friendly personal portfolio website built with React, Vite, and Tailwind CSS. This portfolio showcases my skills, projects, resume, and contact information.

## 🌐 Live Demo

**[View My Portfolio](https://my-portfolio-nine-xi-47.vercel.app/)**

## 📸 About the Project

This portfolio website is designed to present my frontend development skills and projects in a clean and professional way. It includes a responsive layout, dark mode, project showcase, and downloadable resume.

## ✨ Features

- Responsive design for desktop, tablet, and mobile devices.
- Dark mode with LocalStorage persistence.
- Introduction and professional profile section.
- Skills showcase.
- Projects section with live demo and GitHub links.
- Contact section with email and GitHub links.
- Downloadable resume in PDF format.
- SEO-friendly metadata.
- Custom favicon and Open Graph image.
- Smooth transitions and modern UI.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js installed
- npm installed
- Git installed

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Sourabh359/my-portfolio.git
```

**2. Navigate to the project directory**

```bash
cd my-portfolio
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal to view the website.

## 🏗️ Build for Production

To create an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
